# 全 AI 生成项目集

这个仓库里的每一个子文件夹，都是一个**完全由 AI 编写的独立项目**。  
我没有手动写任何一行代码，只负责设计和输入提示词（prompt）。

## 🤖 项目特点

- **零手写代码**：所有源代码、配置文件、文档均由 AI 生成。
- **提示词即源码**：每个项目的起点，只是一段或一组精心设计的提示词。
- **多领域覆盖**：不同子项目可能是小工具、网页应用、脚本、游戏等，完全取决于当天的灵感。

## 📁 结构一览

```text
.
├── project-1/   # 一个完全由 AI 生成的独立项目
├── project-2/   # 另一个独立项目，同样只靠提示词完成
├── project-3/   # ……
└── ...
```

每个子文件夹都包含该项目自己的 `README` 和使用说明。

## 🚀 快速开始

1. 选择你感兴趣的子文件夹。
2. 阅读其中的 `README`，根据说明安装依赖并运行。
3. 如果有任何疑问，记住——连这些说明可能也是 AI 写的 😄。

## 💡 为什么做这个？

我想探索一种**“提示词驱动开发”**的工作方式：  
用自然语言把想法描述清楚，让 AI 去完成从架构到实现的全过程，最后只做结果验证和整合。  
这个仓库就是这种实验的产物。
